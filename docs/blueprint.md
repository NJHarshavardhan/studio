# **App Name**: HirePulse

## Core Features:

- Multi-Tenant Recruitment Pipeline: A visual Kanban board to track candidates through stages like Applied, Shortlisted, and Selected with tenant-specific isolation.
- AI Resume Matcher tool: Automatically parses uploaded resumes and uses a reasoning tool to compare skills and experience against job descriptions, generating a percentage match score.
- Automated AI Interview Agent: An interactive tool that generates dynamic, sequential interview questions based on the candidate's resume and job requirements, evaluating answers in real-time.
- Unified Messaging Center: Centralized communication hub supporting automated Email, SMS, and WhatsApp updates for interview reminders and status changes.
- Intelligent Workflow Engine: A rules-based automation tool that triggers notifications and status shifts when AI match scores exceed predefined thresholds.
- Modular AI Provider Config: Settings dashboard allowing company admins to plug in their own API keys for OpenAI, Gemini, or Anthropic for flexible model usage.
- HR & Candidate Dashboards: Custom views for HR analytics and a portal for candidates to track application progress and complete AI screenings.

## Style Guidelines:

- Primary color: Sophisticated Slate Blue (#3B5BDB) to convey professionalism and technological authority.
- Background color: Ultra-light Ice Grey (#F8F9FC) for a clean, spacious, and non-distracting SaaS environment.
- Accent color: Deep Cerulean (#3B86DB) for high-contrast action items and focused interactions.
- Main font: 'Inter', a modern, machined sans-serif that provides exceptional clarity for data-dense recruitment dashboards.
- Linear, minimalist icons from Lucide for a technical, crisp aesthetic that feels professional and contemporary.
- Structured dashboard layout using side-navigation with high-density cards for candidate data and white-space-optimized pipelines.
- Precise micro-interactions and smooth slide-ins for Kanban transitions to provide immediate tactile feedback.
